# 使用Claude Coding的苍穹外卖项目
# 总共花费了3天时间完成，只剩下支付接口没有完成
#### 介绍
黑马的外卖项目，以后可能会添加一些redis和更多功能

#### 软件架构
Spring Boot + Redis + MySQL + Vue3+微信小程序
#### 安装教程

1. 安装mysql数据库，运行sql脚本创建数据库
2. 安装redis数据库
3. 安装微信小程序开发工具，导入黑马程序员的微信小程序项目，运行微信小程序项目


#### 使用说明
1.  打开苍穹外卖的前端项目，运行nginx服务器
2.  打开苍穹外卖的后端项目，运行spring boot项目
3. 访问http://localhost:8080
